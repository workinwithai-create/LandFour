# LandFour

Four-bar live cadence desk for bedroom producers and AI-music finishers.

The loop is I–V–vi–IV (or a minor axis). It can run all night. LandFour writes the period: authentic ii–V–I, a minor-four sigh on the same bass note, or a Picardy landing. FluidR3 piano, upright bass, and cello. A woodblock keeps time, then leaves on the last bar.

Audio never leaves the tab. No oscillators.

## Distinct from the rest of the line

| Tool | Job |
| --- | --- |
| ThirdFour (yesterday) | A third under the hook, a sixth above. The loop keeps cycling. |
| ReplyFour | Call, then an answer. |
| ShakeFour | Chorus feels bigger. Same level, more percussion. |
| BorrowFour | Four bars that leave the key. |
| AmenFour | Say the last line twice. |
| EndEight / FadeEight | The outro arrangement, or a fade. |
| **LandFour** | Four bars. One cadence. The woodblock stops. The song can sit. |

## Play

Choose a key and a cadence. **Loop** is the problem. **Land** is the period. **Finish it** plays the loop and then the land. Export MIDI of both into the DAW.
